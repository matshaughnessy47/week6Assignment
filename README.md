# GIST 5300 - Assignment 5: ArcGIS API for JavaScript

## Overview

This project demonstrates the use of the ArcGIS Maps SDK for JavaScript to create an interactive 3D web map. The application displays locations that are meaningful to me using custom point symbols, popups, and ArcGIS widgets within a SceneView environment.

## Features

### Custom Location Data
The original `myStuff` object was modified to include personal locations:

- Graduate School: Laramie, Wyoming
- Hometown: Patchogue, New York
- Current Residence: Polson, Montana
- Undergraduate School: Cortland, New York

### Customized Symbology
Point symbols were customized by changing the color, size, and outline of the original markers to improve visibility.

### Customized Popups
Each point displays a popup containing:

- City
- State
- Location category

### Modified SceneView
The default SceneView settings were adjusted by modifying:

- Camera position
- Initial extent
- Lighting and shadow settings

### Click-to-Zoom Function
Users can click on a point and automatically zoom to the selected location.

### Home Widget
A Home button was added to allow users to quickly return to the original map extent.

### Search Widget
The ArcGIS Search widget was added to allow users to search for locations and navigate directly to them.

## Technologies Used

- ArcGIS Maps SDK for JavaScript
- JavaScript
- HTML
- ArcGIS SceneView
